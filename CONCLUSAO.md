## 🔧 Customização Rápida

### Mudar cores (abra `templates/static/css/styles.css` linha 6)
```css
--primary-color: #5B4FA3;    /* Mude para sua cor */
```

### Adicionar novo botão
```css
.btn-custom {
    background-color: #sua-cor;
    color: white;
}
```

### Alterar fonte
```css
body {
    font-family: 'Sua Fonte', sans-serif;
}
```

Veja `EXEMPLOS_CUSTOMIZACAO.md` para mais!

## 📞 Suporte Rápido

### CSS não carrega?
1. Limpe cache: Ctrl+Shift+Delete
2. Reinicie Flask
3. Verifique o caminho do arquivo

### Página sem estilo?
- Certifique-se que está em http://localhost:5000
- Não abra como arquivo local

### Responsividade quebrada?
- Use as classes de grid: `grid grid-2`, `grid grid-3`
- Use flexbox: `flex-center`, `flex-between`
- Teste em F12 (DevTools)
